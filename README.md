# MediaSqueeze

MediaSqueeze is a small Windows GUI tool for compressing, converting, and resizing media files with FFmpeg.

## Features

- Open files from Windows "Open with" command-line arguments
- Select or drag and drop a media file
- Compress video with preset quality modes
- Convert between common video and audio formats
- Resize video output
- Fluent-styled WPF interface

## Build

```powershell
dotnet build MediaSqueeze.sln
```

## Publish

```powershell
dotnet publish MediaSqueeze.csproj -c Release
```
